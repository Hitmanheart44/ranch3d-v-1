# Spirit in the Machine: version negative source

The Godot 4.7 project behind the version negative pre-alpha. Downloads (Linux and Windows) are on the `main` branch's [Releases](https://github.com/Hitmanheart44/spirit-in-the-machine-version-negative/releases).

Run it: install Godot 4.7.2, then `godot --path . res://world/flow/title.tscn`.

Many models, the music and the sound are third-party placeholders that will be replaced; those that need credit are listed in `CREDITS.md` on `main`. The raw asset packs the export leaves out are not included.

Reference only. The game is being rebuilt at https://github.com/Hitmanheart44/spirit-in-the-machine. All rights reserved.
