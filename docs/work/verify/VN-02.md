Require Godot 4.7.2; use bounded subprocess timeouts. For every engine invocation create a fresh `/tmp` scratch parent with isolated HOME/XDG_DATA_HOME/XDG_CONFIG_HOME/XDG_CACHE_HOME. Promotion roots use `vn-01-`; loop roots use `vn-02-`. Export only the appropriate scene scratch marker. The new scene proves globalized Save.PATH lies under its scratch root and is `user://save_test.json` before any Save access; require a fresh absent file. Keep logs, especially on failure.

Fail for missing engine, nonzero exit, timeout, script/runtime error text even with zero exit, or absent expected completion verdict. Small temporary fake engines validate these cases without modifying production files. Positive runner checks verify process arguments, independent per-process scratch directories, expected markers, invocation from another caller directory and executable paths with spaces. Failure fixtures remain under fresh temporary test storage.
